# Cazafalacias

Aprende y estudia las falacias lógicas y argumentativas: un catálogo de falacias por categoría y casos para practicar identificándolas.

Forma parte de [PROYECTO LEARNING](https://github.com/fabianbauttt/PROYECTO-LEARNING), del Prof. Fabián Bautista G.

## Cómo usarlo

- **Jugar:** <https://fabianbauttt.github.io/cazafalacias/>
- **En local:** abre `index.html` en el navegador. No necesita instalación.

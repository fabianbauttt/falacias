# Cazafalacias

Aprende y estudia las falacias lógicas y argumentativas: un catálogo de falacias por categoría y casos para practicar identificándolas.

Forma parte de [PROYECTO LEARNING](https://github.com/fabianbauttt/PROYECTO-LEARNING), del Prof. Fabián Bautista G.

## Cómo usarlo

- **Jugar:** <https://fabianbauttt.github.io/cazafalacias/>
- **En local:** hay que servir la carpeta con un servidor web; abrir `index.html` con doble clic no funciona, porque el navegador bloquea los módulos de JavaScript (`app.js`, `data.js`) cargados desde `file://`. Por ejemplo, desde la carpeta del juego ejecuta `python3 -m http.server` y entra a <http://localhost:8000>. No necesita instalación.

## Panel docente

El Catálogo tiene un botón **Panel docente**, protegido con contraseña; no aparece durante la Práctica. Incluye el resumen de la herramienta, la solución de los 36 casos de práctica agrupados por familia, una guía de uso en dos sesiones, preguntas de discusión, una rúbrica y una ficha imprimible («Libreta del cazador»).

El contenido está cifrado en `panel-docente-datos.js`, así que no se puede leer abriendo el código fuente. `panel-docente.js` es el módulo común que muestra el panel. Para editar el material, ver la herramienta del panel docente en [PROYECTO-LEARNING](https://github.com/fabianbauttt/PROYECTO-LEARNING/tree/main/herramientas/panel-docente).
